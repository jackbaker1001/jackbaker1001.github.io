## Mathematics

Inline maths uses dollar signs: the variational principle says
$E_0 \le \langle \psi | \hat H | \psi \rangle$ for any normalised $|\psi\rangle$.
Display maths uses double dollars:

$$
\hat H = -\sum_i \frac{\nabla_i^2}{2} - \sum_{i,A} \frac{Z_A}{|\mathbf r_i - \mathbf R_A|}
       + \sum_{i<j} \frac{1}{|\mathbf r_i - \mathbf r_j|}
$$

## Code

```python
import pennylane as qml

dev = qml.device("default.qubit", wires=2)

@qml.qnode(dev)
def bell(theta: float):
    qml.Hadamard(wires=0)
    qml.CNOT(wires=[0, 1])
    qml.RY(theta, wires=1)
    return qml.expval(qml.PauliZ(0) @ qml.PauliZ(1))  # ⟨Z⊗Z⟩
```

Inline code such as `qml.qnode` is set in the mono face.
