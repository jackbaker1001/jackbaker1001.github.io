# Brand

The identity for jackstephenbaker.com is **Graph State**: a ket whose contents are a graph, |G⟩. It reads as benzene, as a ring of qubits and as a graph neural network, and is set in Computer Modern.

The full brand book (tokens, type scale, logo rules, voice and components) is the design system at https://claude.ai/artifact/CAo9Evo2g4jFR5Lq1Ao8z5.

## graph-state/ (use this)

| Folder | Contents |
| --- | --- |
| `logo/` | `lockup-*`, `lockup-stacked-*` and `mark-*` in light, dark and `mono` (`currentColor`) SVGs, with text outlined |
| `favicon/` | `favicon.ico` (16/32/48), adaptive `favicon.svg`, `apple-touch-icon.png`, `icon-192/512.png`, `icon-maskable-512.png`, `site.webmanifest`, `head-snippet.html` |
| `social/` | `og-light.png` / `og-dark.png` (1200×630 link previews), `avatar-light.png` / `avatar-dark.png` (800×800 profile pictures) |
| `pattern/` | Honeycomb lattice swatches and a seamless `lattice-tile.svg` for CSS backgrounds |
| `fonts/` | WOFF2 subsets: New Computer Modern Book, Italic, Bold, Mono and Math, plus CMU Sans Serif |
| `tokens.css` | Light and dark colour tokens, font stacks, spacing, radii and `.t-*` type styles |

## explorations/

The seven directions considered on the way (A–D in round 1, E–G in round 2), kept for reference. Graph State grew out of `e-graph-state/`.

Fonts: New Computer Modern is under the GUST Font Licence; CMU fonts are under the SIL Open Font Licence. Both allow self-hosting on the web.
